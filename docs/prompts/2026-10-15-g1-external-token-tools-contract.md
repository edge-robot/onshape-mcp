# G1: single-source external-token tool allowlist and contract snapshot test

## Goal

Make the external-token `tools/list` catalog a tested contract artifact:

1. The external-token tool allowlist exists **once**, as pure logic in `onshape-mcp-core`.
2. `onshape-mcp-io` uses it for both listing and call denial. Behaviour stays unchanged.
3. A new contract test `crates/onshape-mcp-core/tests/contract.rs` proves that the
   external-token catalog exactly matches the contract snapshot
   `tests/contract/mcp-tools.json`, and that the fixture copy has the expected version.
4. The behaviour of `onshape_auth_status` with `validate: true` in external-token mode
   is pinned by a test and reported (contract gap G12, investigation only).
